# 2016〜2020年の追加期間検証

2026年11月6日、ユーザーは検索機能の削除判断の前に2016〜2020年で追加検証するよう依頼した。入口・パラメータは既存の7設定を固定する。主対象は同じ日本個別株50銘柄、ETF20銘柄は別集計。上場前・履歴不足は明示し、現在の銘柄一覧による生存者バイアスを残した追加過去期間検証とする。

評価期間2016-01-04〜2020-12-30、準備期間2014年以降。検索の共有関数を直接使い、固定保有5/10/20/40/60営業日と同じ銘柄・年の全ready日基準を中心に2021〜2025年と比較する。既存の出口A/B/C/D・初期ストップ3/5/8/10/12%・C/D基準幅8%も変更せずに再評価する。値を追加探索せず、最良値だけで採否を決めない。

調整済み日足、同額元本の独立仮想取引、翌寄付、片道手数料0.1%・スリッページ0.05%、保有期限なしの出口診断を維持する。資金上限なし・同一銘柄重複あり。期末建玉は別表示。実注文・main更新は行わない。

Yahooの許可済みquery2 chartから取得し、yfinance自身のparse_quotes/auto_adjustで変換する。認証ヘッダーやプロキシを変更せず、元JSONとハッシュを保存する。最初の取得失敗で停止し、取得済み原本を再利用する。不整合行を検出した場合は補正せず監査一覧へ保存し、実質的補正の必要性を報告する。

オルカン実ファンドの基準価額は2016年まで遡れないため、この検証ではオルカン比較を行わない。仮の一定価格や別指数をオルカンとして使わず、比較欄は欠損とする。固定保有と出口の既存計算を再利用し、共有入口式は変更しない。
