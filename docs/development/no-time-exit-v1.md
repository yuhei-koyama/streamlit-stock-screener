# 保有期限撤廃のテスト設計と実装計画

承認仕様はno-time-exit-v1.mdの1.0-approved、R-NT01〜R-NT06。2026年11月5日。

## テスト設計

- Aの20営業日期限を過ぎる上昇価格の固定データで、期限ありは翌寄付決済、期限なしは期末保有になることを確認する。
- Bの反対シグナル・RSI回復・初期ストップ・トレーリングは期限撤廃後も既存の期待日と価格で成立することを確認する。
- 期限あり・なしの全取引について、同じ買いシグナルから購入され、元本と費用が一致することを確認する。
- 期末時価100→120、元本1の例で含み損益率とオルカンの同日付評価を確認する。空の完了取引・期末保有・古い価格・重複IDも検証する。
- 既存結果の読み込みと既定設定を含めた全自動テストを実施する。
- 実データ14条件で日数決済が0件、入口一致、完了＋未決済の全件対応、損益率・オルカンとの差・集計・保存ハッシュを確認する。

## 実装計画

1. 共通の出口判断と設定へ日数決済の有効/無効を追加し、通常CLIから指定可能にする。
2. 期末評価を含むオルカン比較を追加する。閉じた取引の既存集計も保存する。
3. 合成テストと全回帰テスト後、承認済み補正入力で期限なし14条件を実行する。
4. 保存済みの期限あり結果にも同じ期末評価を適用し、同じ入口群で変化とオルカンとの差を集計する。
5. 結果と制約を日本語で保存する。
