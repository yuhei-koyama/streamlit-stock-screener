# オルカン比較のテスト設計と実装計画

2026年11月5日。承認仕様はall-country-comparison-v1.mdの1.0-approved、R-OC01〜R-OC04。

## テスト設計

- 基準価額100から105と戦略純損益率8%の取引で、オルカン5%、差3ポイント、元本1に対する期末額1.05と1.08に一致することを確認する。
- 同日決済はオルカン0%、欠損日付は停止、日付の重複・順序・非正値も停止する。
- 取引を等加重して平均差・中央値差・上回り率を集計し、購入年別・銘柄別の件数と全体の一致を確認する。
- 元本・元の戦略損益率・取引IDと期間を維持する。
- 通常CLIで全14条件と日本語報告書・CSV・メタデータを保存し、元結果と公式原本のハッシュを照合する。

## 実装計画

1. 公式CSVのファンド名と列を検証し、分配金再投資基準価額の系列へ正規化する。
2. 保存済み独立取引へ同期間のオルカン損益率・差・正規化期末額を付加する。
3. 条件別・銘柄別・購入年別・資産区分別の集計と日本語報告、再現用の入力・コードハッシュを保存する。
4. 合成テストと関連回帰テストを実行後、実データ全14条件を計算し、元結果・公式データと照合する。
