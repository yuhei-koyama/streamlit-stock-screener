# 売買戦略の仕様化方針

作成日: 2026-11-05 / 版: 1.0-draft / 状態: **調査結果＋未決定事項**

## 1. 共通仕様テンプレート

各戦略は `strategy_id + definition_version + source_version + parameter_set_id` で識別し、次を承認するまで実装しない。

1. 正本とする原典・版・ページ、公開資料、プロジェクト固有の仮定
2. 対象母集団、個別株/ETF、ロング/ショート、流動性
3. 日足/週足、タイムゾーン、取引カレンダー、価格系列
4. 指標式、期間、初期化、ウォームアップ、欠損
5. 銘柄選別、相場フィルター、セットアップ、エントリートリガー
6. シグナル確定、注文可能時刻、注文種別、ギャップ時の価格
7. 初期損切り、利確、トレーリング、時間切れ、通常決済
8. 複数出口が同じ日足で成立した場合の優先順位
9. ポジションサイズ、追加購入、最大保有、資金不足、売買単位
10. 手数料、スリッページ、値幅制限、売買停止、企業行動
11. パラメータ探索範囲、IS/OOS、ウォークフォワード
12. 成立・不成立・データ不足の具体例と理由コード

選別条件、エントリー、出口、サイズを交換可能な別ポリシーにする。これにより「入口の質」と「完全な売買システム」を分けて比較する。

## 2. LBR 3/10 Oscillator / Anti

### 確定した指標

`lbr_310`:

```text
Fast = SMA(Close, 3) - SMA(Close, 10)
Slow = SMA(Fast, 16)
Histogram = Fast - Slow
```

全窓が揃うまで値は欠損とする。0始まりでFastの最初の有効位置は9、SlowとHistogramは24。

`lbr_stochastic_7_4_10`:

```text
RawK = 100 * (Close - LowestLow(7)) / (HighestHigh(7) - LowestLow(7))
Fast = SMA(RawK, 4)
Slow = SMA(Fast, 10)
```

高安幅が0の窓は推測値で補完せず欠損とする。0始まりでRawKは6、Fastは9、Slowは18から有効になる。

資料:
- [Linda Raschke公式サイト掲載Active Traderインタビュー](https://lindaraschke.net/wp-content/uploads/2026/03/raschke_pt2_0304.pdf)
- [Linda Raschke公式サイト掲載インタビュー](https://lindaraschke.net/wp-content/uploads/2013/11/Discerning-trader.pdf)
- Raschke/Connors『Street Smarts』Chapter 9

### `lbr_anti_stochastic_v1`

原典比較用の7/4/10版。Slowがトレンド方向を維持する間、Fastが逆方向へ連続して押し、再びSlow方向へフックする形を検出する。3本の対向傾斜は、今回の機械化ではセットアップ成立条件として採用する。前日高値・安値の逆指値、初期ストップ、クライマックス出口は今回実装しない。

### `lbr_anti_310_adaptation_v1`

3/10オシレーターへ同じ概念を適用するプロジェクト固有版。Slowのゼロ線クロスは要求しない。押し期間は3本を初期値とし、2本へ切替可能にする。FastがSlowへ接触することは許可し、反対側への通過を許すかはパラメータ化する。

両版の機械化条件、状態、理由コード、詳細テストは [lbr-anti-logic.md](lbr-anti-logic.md) を正本とする。`First Cross`はAntiと混ぜず、今回の対象外とする。

### 未承認

- 価格によるエントリートリガー、注文時刻・価格。
- 初期損切り、通常出口、利確、保有期限。
- 収益性または原典完全再現の主張。

3/10 OscillatorとAntiセットアップは、単体では完全な売買戦略ではない。

## 4. RS（相対強度）＋ブレイクアウト

### 定義上の問題
RSはRSIではない。少なくとも次があり、名称だけでは再現不能である。

- 専有のRelative Strength Rating
- 銘柄価格をベンチマークで割ったRS Line
- 複数期間リターンの独自加重スコアと横断面順位

専有Ratingを無料で正確に再現できるとは限らない。再現可能な独自式を採る場合は `rs_cross_sectional_jp_v1` 等の別名にし、全式、順位母集団、欠損処理を公開する。

参考資料:
- [IBD公式Buying Guide](https://get.investors.com/wp-content/uploads/2024/08/IBDD-How-to-buy-Stocks-infographic.pdf)
- [IBD公式資料](https://shop.investors.com/Images/promotional/Wizards-QA.pdf)

### 未決定
- RSの種類、ベンチマーク、期間、加重、順位母集団、閾値。
- 時点別母集団で横断面順位を計算できるデータ品質。
- ブレイクアウト窓。判定当日を過去高値窓に含めないこと。
- 高値/終値のどちらで成立するか、ストップ注文か翌日注文か。
- 出来高増加、ベース、流動性、ギャップ上限を使うか。
- 出口、損切り、サイズ。

## 5. タートルズ・ブレイクアウト

### 原典から確認できる構造
Original Turtle Rulesは、2種類のブレイクアウト、N（ボラティリティ）によるサイズ、追加ユニット、ストップ、チャネル出口、前回ブレイクアウト結果による規則、単一・相関市場の上限を含む完全な先物ポートフォリオシステムである。一般に知られる20/55期間の入口と10/20期間の出口だけを抜き出したものは原システム全体ではない。

資料:
- [Original Turtle Rules公開ページ](https://tradingblox.com/originalturtles/originalturtlerules.htm)
- [原規則PDF](https://www.tradingblox.com/originalturtles/originalturtlerules.pdf)

### 日本株向け派生版で決めること
- System 1/2を分けるか、両方を同時に使うか。
- 初期はロング現物だけか、空売りを扱うか。
- 前回ブレイクアウトの仮想損益を追うスキップ規則。
- Nの厳密な計算・初期化、円建てリスク、売買単位への丸め。
- ピラミッディング、最大ユニット、業種やETF重複エクスポージャー上限。

日本株現物への適用は `turtle_equity_jp_*` のような派生版として原典版と区別する。

## 6. VCP

### 確認できた構造
VCPは、上昇段階の銘柄で値動きと供給が段階的に収縮し、右側のピボット突破を狙うセットアップとして説明される。Trend Templateが選別、VCPがセットアップ、ピボット突破がエントリーという分離が必要である。

公開された原典寄り資料は考え方を示すが、完全な機械判定式を提供しない。人が完成後のチャートを見てラベルを付けると、ルックアヘッドと選択バイアスが入りやすい。

資料:
- [Minervini公式ドメイン掲載VCPレビュー](https://cdn.minervini.com/static/dist/mtp-review.1f8e8633.pdf)

### 未決定
- Trend Templateを必須前提にするか。
- スイング高安の検出法、収縮回数、深さ、長さ、縮小率、安値切上げ。
- 出来高枯れとブレイク時出来高の式。
- ピボット、ブレイク、失敗ブレイクの定義。
- 形成途中の時点で判定可能であることの証明方法。
- 人手ラベルを使う場合の手順、複数評価者の一致、固定評価セット。
- 損切り、出口、サイズ。

機械化した版は `vcp_algorithmic_v1` 等の検証仮説とし、「VCPの完全再現」と表示しない。

## 7. 比較設計の提案

同じ戦略名でも、次を別々に比較する。

1. 選別器だけの品質: 将来一定期間のリターン分布。これは売買成績ではない。
2. 共通の標準エントリー・出口・サイズを適用した比較: 選別/入口の差を見やすくする。
3. 戦略固有の出口・サイズを含む完全システム比較: 原典または派生システム全体を評価する。
4. コスト0、現実的コスト、ストレスコストの感応度。

最良の組合せだけを表示せず、試した戦略・出口・パラメータ数と全分布を保存する。
