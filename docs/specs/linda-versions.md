# リンダ系の版別ページと判定契約

2026-11-05: ユーザーは添付Pine版・現行Anti各版のページ分離と、削除した初期試作版の復元を明示依頼した。旧版を廃棄する以前の指示について、本書の試作版復元に限り上書きする。原典準拠版の新規定義は行わない。

## 版の固定
- `tv_ema_stoch_v1`: 添付Pine v6のEMA3−EMA10、EMA16 Signal、RawK7→SMA3→SMA10。MACD上抜けとKの谷かつD上昇が同じ足で成立したらBUY、逆でSELL。Setup条件を後付けしない。初期値はPineと同じ、全期間を指定可能。正整数のみ。
- `lbr_anti_310_adaptation_v1`: 既存SMA3/10/16の共通関数を再利用。押し2/3本、交差許可を維持。Hook Long/Shortを候補列として返すが、価格によるentryとは呼ばない。
- `lbr_anti_stochastic_v1`: 既存7/4/10関数を再利用。押し3本・交差許可固定。
- `legacy_ema_sma16_v1`: 初期mainコミット8f7aa99のcalculate_linda_macd/check_conditionsを判定の正本とする（eb8908bにも同じ有効計算が残る）。EMA3−EMA10、SMA16 Signal、終値SMA16。Histogramが谷かつ終値>SMA16なら試作BUY、山かつ終値<SMA16なら試作SELL。GC/DCも別列に保持。元の30行未満は判定なしを維持。使われない変数や例外の握り潰し・米国株/FX画面は復元しない。原典Antiではなく比較対象。

## 共通処理
売買損益・注文・出口を追加せず、入力を変更しない純粋関数evaluate_versionで足ごとの指標・候補・ready・strategy_id・definition_version・source_version・parameter_setを返す。版とパラメータを混在させない。PineのEMAは最初の有効値から再帰計算し、ストキャスの最高安値窓は系列先頭で存在する足を利用する。SMA3とSMA10は必要な値が揃ってから有効にする。TradingView移植版では欠損・高安幅0は候補化せず、入力の欠損後は連続区間で再初期化する安全規則とする。初期試作版は欠損を含むEMA処理も元のpandas式を保持し、既存Antiは既存の欠損リセット規則を保持する。この欠損時規則、データ供給元・履歴開始点の差のため、TradingView実データとの完全一致は未検証と表示する。欠損のない同一系列での式の再現をテストする。

## UI
既存Antiトップページとミネルヴィニ/RSIページを維持し、4版を独立ページとして追加。70銘柄プリセット、100件上限、逐次手動取得と既存キャッシュを再利用。最新足BUY/SELL（AntiはHook）、準備、全件のフィルター、判定日、過去の候補発生日、指標・価格チャート、CSVを提供。Setupがない版にSetupを捏造しない。
当日足除外は従来通り初期有効。市場終了の自動判定は今回追加しない。除外時は引け後も当日が除外されること、解除時は場中未確定足を含み得ることを明示。取得日時と判定対象日は区別する。

## 検証計画と範囲
合成データでEMA手計算、Pineの同時成立・厳密不等号・交差前日等値、未来不変性、版分離、初期実装の実関数との回帰比較、各ページ初期表示と検索操作を確認。Pine原文を参照ファイルとして保存。実市場での照合・バックテスト・最適化・デプロイは行わない。

## 正本の保存
ユーザー添付Pineはdocs/references/tradingview-linda-v1.pineに保存。初期版の計算・判定関数はtests/fixtures/legacy_original.pyに初期コミットから変更せず抽出し、回帰テストの比較対象とする。UIのみの装飾や旧市場選択は再現対象外。
