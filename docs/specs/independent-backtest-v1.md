# 各シグナルの独立仮想取引 v1

文書版は1.0-approved。2026年11月5日、ユーザーが本会話で引用した4条件を明示承認した。

## 承認された要求

- R-IV01。各買いシグナルを独立した仮想取引として評価する。同一銘柄の保有期間が重なったシグナルも対象にする。
- R-IV02。各取引の元本を同額へ正規化し、コスト控除後の損益率で比較する。購入株数の切捨てによる元本差を生じさせないよう、仮想の端数数量を用いる。
- R-IV03。資金上限と同時保有数による見送りをなくす。
- R-IV04。翌営業日寄付、既存出口A/B、初期8%損切り、片道手数料0.1%、片道スリッページ0.05%を共通にする。出口A/Bの定義はbacktest-approved-v1.mdを参照する。
- R-IV05。既存の7設定、70銘柄、2021年1月4日〜2025年12月30日、2019年以降の指標準備期間を使用し、検索と同じ判定関数を共有する。
- R-IV06。結果を後から参照できる形で保存し、説明文書は日本語とする。

## 現状と今回の整理

現行実装は有限資金のポートフォリオを計算する。独立取引を保存する評価方法を追加する。ユーザーの今回の指定により、有限資金評価は今回の実行対象から外れる。

固定利確と追随利確の比較対象追加は承認済み。数値と境界条件はexit-comparison-v1.mdに提案として保存済みで、今回明示された既存出口A/Bを先行対象とする。

実データは探索モードの調整済みOHLCを使用する。分割・配当は価格調整に含み、配当の現金加算は行わない。正規化元本は計算上1とし、損益率は任意の同額元本に換算できる。

## 継続する境界条件

- 各検証日終値のreadyとbuy_signalが成立した行から、次の検証営業日寄付への新規仮想取引を作る。連続する買いシグナルもそれぞれ数える。
- 新規注文日の欠損・出来高ゼロ・売買不可は理由とともに記録する。保有売却の不可は次の可能日へ繰り越す。
- 約定日の足を1日目とする。時間期限と反対候補・RSI回復は引けで判断して翌営業日寄付で決済する。ミネルヴィニの最高値更新は翌営業日から有効にする。
- ギャップストップと日中ストップ、コストの処理順序は既存エンジンの共通処理を利用する。
- 期末保有は未決済一覧と時価評価を保存する。完了取引の損益統計と未決済の評価を区分する。

## 集計と保存

取引件数、平均・中央値の純損益率、勝率、平均利益率、平均損失率、プロフィットファクター、平均保有営業日数を集計する。銘柄別・エントリー年別・個別株/ETF別の集計、全取引、未決済、見送りをCSVで保存する。設定、コード版、入力とコードのハッシュ、実データ/合成データの区分、実行状態をJSONへ保存する。

同じ銘柄の重複取引を含む取引統計である。資金曲線を作るには資金配分と取引間の資金再利用の規則が必要になるため、この独立評価では取引単位の損益率を報告する。
