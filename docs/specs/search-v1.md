# 追加検索仕様 v1

2026-11-05: ユーザーは検索機能とバックテストを分離する認識を確認し、各種検索機能の実装を依頼した。本版は直前の提案の検索条件のみを採用する。出口・仮想売買・損益計算は含めない。バックテスト実装案は未実装。

## 構成
既存app.pyのAnti（3/10適応版と7/4/10版）はそのまま維持。Streamlitのサイドバーのページ選択から「銘柄検索」を開く。追加検索はstock_screener/search.pyの純粋関数を呼ぶ。最大100銘柄、手動実行のみ、価格取得は既存の15分キャッシュを再利用。実装検証に外部APIを使わない。

## ミネルヴィニ派生版
- Close > SMA50 > SMA150 > SMA200。
- SMA200 > 20本前のSMA200。
- Close >= 過去252本Low最小値 × 1.3、Close >= 過去252本High最大値 × 0.75（この窓には当日を含む）。
- RS126 = (Close / 126本前Close) / (比較対象Close / 126本前比較対象Close) > 1。
- 当日Close > 当日を除いた過去20本High最大値。
- 当日Volume > 当日を除いた過去20本Volume平均 × 1.5。

template_passとbreakout_passとvolume_passを満たす場合にmatchとする。比較対象の初期値は1306.T（TOPIX連動ETFの代理系列）で、変更可能。専有RS Ratingや原典の完全再現を名乗らない。比較対象は日付の完全一致で対応付け、欠損を補完しない。

## RSI平均回帰
Wilder RSIを2/14で切替。最初の平均上昇幅・下落幅は期間分の差分の単純平均、その後はWilder平滑。上下変化とも0なら50、下落のみ0なら100、上昇のみ0なら0。欠損で初期化し直す。
初期閾値はRSI2が10、RSI14が30で変更可能。RSI < 閾値かつ、初期有効のClose > SMA200フィルターを満たす場合にmatch。フィルターは解除可能。

## 表示と制約
当日足を常に除外。成立銘柄のみの絞り込みと、データ不足を含む全件表示を提供。判定日・成立・状態、価格チャート、直近30本の条件別合否と中間値、CSVを表示。条件変更後は再検索が必要。取得失敗は銘柄別に表示。
Yahoo Financeの調整済み日足を使い、勝率・収益性は評価しない。取引所カレンダーによる鮮度判定、ETF商品分類、iPhone実機、実データ疎通は未検証。

## 検索対象拡大（2026-11-05）
ユーザーの検索対象拡大依頼に基づき、日本個別株50・国内ETF20・合計70の共通プリセットを追加。Antiと追加検索で共有する。追加検索の入力上限は100とし、候補をコード欄で編集可能とする。手動管理の代表例であり網羅性・最新の上場状態は保証しない。取得は実行ボタン押下時に逐次行い、既存キャッシュを維持し、進捗を表示する。本作業中に実市場データを一括取得しない。
