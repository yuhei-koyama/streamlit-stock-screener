# 調整済み価格による探索検証 v1

2026-11-05: ユーザーはローカル実行を選択し、調整済みOHLC・仮想1株単位・配当別加算なしによる探索検証への修正をサブブランチに依頼した。これは当時の実単元による厳密会計とは別モードとする。

## 変更するもの
- 検索と同じyfinance調整済みOHLCを判定と疑似約定の両方に使用。
- 購入数量は仮想1株単位の整数。実在の単元/株数を表さない。
- 分割/配当調整は調整済み価格に含まれるものとして扱い、数量の分割処理と配当現金加算は無効（Split=1、Dividend=0）。
- 実データ/合成データの区分と、厳密/探索の約定モードを別々に記録する。実単元での運用成績と誤認させない。
- 70銘柄を一度取得・保存し、検証済みハッシュに一致する取得済みファイルを明示的な--resumeで再利用。最初の取得失敗で停止し、無制限リトライしない。
- 保存済みソースから探索入力を生成する処理はネットワークを使わない。判定用と約定用のOHLCVが同じであること、仮想1株・無配当加算を実行前に検証する。

## 維持するもの
既存screening_signalsから検索関数を直接呼ぶ。全7設定×出口A/B、2021-01-04〜2025-12-30、2019年からのウォームアップ、翌営業日寄付、1000万円・5銘柄・20%、コスト、20/40/5営業日の保有期限、損切り・トレーリングは変更しない。原典準拠の新規主張や最適化を行わない。厳密モードの入力検証は緩めない。mainは変更しない。

## 限界
調整済み価格上のストップや仮想数量は実際の現金配当・単元・指値/逆指値の完全な再現ではない。現在の70銘柄による生存者/選択バイアス、Yahooの更新・価格調整、流動性/値幅制限の近似が残る。営業日は取得済み日付の和集合を使うため、全銘柄が同時に欠落した営業日を識別できない。実データの成績と合成動作確認を明確に区別する。

## 検証と提供
固定合成データで準備・読み込み・14条件実行・ZIP作成、厳密モードとの分離、配当二重加算防止、取得再開時のキャッシュ照合を検証する。今回クラウド上で実データを取得/実行しない。Windows PowerShellとLinux/macOS向けローカル手順を保存する。
