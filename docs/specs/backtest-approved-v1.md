# 承認済みスイング検証 v1

2026-11-05、ユーザーは直前に提示された入口・出口A/B・共通条件・実行範囲を承認し、検索と全く同じ判定ロジックの利用を再確認した。以前の実データバックテスト禁止は、本書の限定実行について解除された。main反映、実注文、最適化は許可されていない。

## 固定対象
TradingView添付・Anti310（押し3、交差許可）・Anti7410・初期試作・ミネルヴィニ派生・RSI2（10未満）・RSI14（30未満）の7設定、各出口A/Bの最大14条件。RSIのSMA200フィルターは有効。既存トップページの重複集計なし。個別株50・ETF20の現行リスト、期間2021-01-04〜2025-12-30、ウォームアップ2019年以降。売買ロングのみ。

## 入口の同一性
リンダ系はstock_screener.linda_versions.evaluate_version、その他はstock_screener.search.search_minervini/search_rsiを直接呼ぶ。別のMACD/RSI/Anti計算式をバックテスト内に持たない。各足でそのページの候補が成立し未保有なら翌営業日の寄付注文を出す。Setupでは買わない。ミネルヴィニのベンチマークは1306.T。計算に渡す価格系列・履歴開始点を保存し、同じデータと設定でのみ同一性を主張する。検索UIの現在日の除外は過去の足には不要。

## 出口と会計
A: 買付価格8%下ストップ、20営業日経過を引けで判断し翌営業日寄付売却。固定利確なし。
B: リンダ4版はそれぞれの反対候補か20営業日、RSIは50以上へ回復か5営業日、ミネルヴィニは前日までの保有最高値から10%下のトレーリングか40営業日。全て初期8%ストップあり。
寄付がストップより低ければ寄付で売却し、売りスリッページを加算。引けで更新した最高値は翌日から使う。約定日の足を1日目とする。売却を先に処理し、その後の寄付買付、日中ストップ、引け判定の順。日中売却で得た資金をその日の寄付買付に使わない。
資金1000万円、最大5銘柄、各銘柄買付時NAV20%以内、ティッカー順、片道手数料0.1%・スリッページ0.05%。単元・資金不足は切捨てか拒否、追加購入なし。保有中のBUYは無視。次の引けで新しいBUY候補が成立した場合のみ翌寄付から再購入可能。取引不可の新規注文はその営業日に取消、保有の売却注文は次の取引可能日へ繰越。期末は強制決済せず未決済建玉と純資産を分ける。

## データの前提
判定用は検索と同じ調整済みOHLCV。現実の単元と資金管理には別途、名目の未調整OHLCV・日付別売買単位・分割・配当の権利/支払日が必要。分割で数量とストップ等の価格を調整し、配当は権利発生時に未収、支払日に現金化する。調整済み価格の疑似約定と現物単元を混ぜない。CSVの単元を推測せず、配当支払日不明や分割端数がある入力は実行を拒否する。YahooのOHLCが単にauto_adjust=Falseだから歴史的な名目価格だとは断定しない。供給元の検証と必要列が揃わない場合は実市場結果を作らず不足を報告する。
現在の母集団による生存者バイアス、配信訂正、売買停止・値幅制限の完全再現不足を明記した探索検証とする。取得データ・設定・コード版・ハッシュ、拒否注文、売買履歴、期末建玉、純資産曲線を保存。CAGRは現金・未収込み、実日数。個別株/ETFは取引統計と損益寄与を分け、混合ポートフォリオから独立資産群のCAGRを捏造しない。

## テスト方針
検索関数との全行一致、未来行変更で過去約定不変、翌営業日約定、資金/単元/最大保有、コスト、重複保有、ギャップストップ、トレーリングの翌日有効、分割と配当会計、CAGR、欠損取引停止、期末建玉を固定合成データで検証してから限定実データ実行。
