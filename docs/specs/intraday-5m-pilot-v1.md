## 5分足と取引時間の提案

## 足内の処理順と大引けの近似案

1. 始値でギャップ時の価格出口を判定し、続いて既存の予約売却を処理する。
2. 同じ時刻の買い候補をコード順に処理する。
3. その足で有効なストップ・利確を高安値で判定する。同じ足で両方に達した場合はストップを優先し、曖昧約定を記録する。
4. 足が確定した後に評価額・売買シグナル・切り上げ段階を更新する。更新した水準は次の足から有効にする。
5. 15時25分で残る保有には大引け売却を予約し、15時30分に執行する。

買い価格は次足始値に買いスリッページを反映する。ストップを下回って始まった足は始値、足内のストップ到達はストップ水準を基準に売りスリッページを反映する。利確は目標指値を基準に手数料を控除する。

大引けは同日のYahoo日足終値を基準に、売りスリッページと手数料を反映して全量約定する仮定を提案する。5分足の終端行・日足終値・当日の出来高・最終観測時刻を照合し、日足終値と最終分足終値の差も保存する。日足終値を売買判定に使う時刻は15時30分とする。

引け価格が確認できない保有は`unclosed_due_to_missing_close`として記録し、その条件の当日以降の資産経路を確認待ちにする。最後の観測価格による参考評価と、未決済数量・最終時刻を別保存する。完了したデイトレ成績の順位に含める対象は、全日で決済状態を確認できる条件とする。

日足終値での全量約定は短期試作の価格近似。大引けの板・注文順位・実際の約定可否の評価には追加の約定情報が必要になる。[JPX売買成立の方法](https://www.jpx.co.jp/equities/trading/domestic/04.html)

## 欠損・価格異常への提案

- 期待する取引日・通常5分区間と実際の観測時刻を照合する。昼休み、休場日、プレクロージングの無約定時間を取引時間として扱うことによる誤検出を防ぐ。
- 次の予定足がない買い注文は取消とし、後続の足へ遅延させた買付は新しい確定シグナルから判定する。
- 有効価格・出来高0の足は約定不可として保持する。欠損足の原因は無取引・売買停止・取得欠損の可能性を記録する。
- 実際の欠損では指標計算を連続した有効区間へ分け、各共有関数で再準備する。通常の昼休み・日付変更では指標状態を継続する。
- 保有中に足が欠けた区間では、ストップ・利確到達と約定順序が不明な件数と保有を記録する。その区間を含む成績には価格経路の留意事項を付ける。
- 全対象共通の足欠損、RS参照の欠損、OHLC不整合、負価格、日足との価格単位差、取得期間の不足を一覧にする。新しい補正候補は元値・銘柄・時刻・ハッシュを保存して確認する。
- 同じ不整合について既に承認された適用条件がある場合は照合し、その範囲で処理する。
