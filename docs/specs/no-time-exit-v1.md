# 保有期限撤廃の追加検証 v1

文書版は1.0-approved。2026年11月5日、ユーザーは「出口案から、保有期間を撤廃した場合も検証して。更に上昇を汲み取る狙い」と明示依頼した。

## 現状と承認範囲

既存の出口Aは初期8%損切りと20営業日期限、出口Bは初期損切りに反対候補・RSI回復・トレーリングと戦略別の5/20/40営業日期限を組み合わせている。独立仮想取引の入口、同額元本、コスト、取得済み70銘柄・2021〜2025年のデータ条件を継続し、日数を理由とする決済だけを切り替えて検証する。

| 要求ID | 承認内容 | 確認方法 |
| --- | --- | --- |
| R-NT01 | 既存出口A/Bへ保有日数の決済を無効化する設定を追加する。通常の初期値は日数決済ありとする。 | 期限到達後も建玉を保持し、従来設定が従来結果に一致することを確認する。 |
| R-NT02 | 期限撤廃時、Aは初期8%損切り、Bは初期損切りと既存の反対候補・RSI回復・トレーリングを使用する。 | 損切り・ギャップ・翌寄付決済・翌日有効トレーリングの期待値を確認する。 |
| R-NT03 | 各買いシグナルを同額で独立評価し、期限あり・なしを同じ購入シグナルで比較する。 | 取引ID・購入日・購入価格・数量の対応が全件一致することを確認する。 |
| R-NT04 | 期末未決済を含む全取引の評価と、決済済み取引の評価を併記する。 | 完了＋期末保有の件数を照合し、元本1に対する期末時価から含み損益を再計算する。 |

## 期末評価の扱い

期限撤廃では大きな利益を持つ取引が期末まで残る可能性がある。全取引の評価は、決済した取引には費用控除後の確定損益率、未決済には既存の期末時価評価の損益率を使用する。未決済分は売却費用をまだ発生させていない評価であり、売却注文は追加しない。最終価格の参照日も保存し、期末より古い価格を使った件数を表示する。

オルカンは決済済み取引には購入日〜実際の決済日、未決済には購入日〜検証期末の日次再投資基準価額を対応させる。すべて同額元本、取引等加重で比較する。期限あり・なしでは保有期間自体が変わるため、それぞれの同期間オルカンとの差も併記する。

決済済み取引だけの集計は補助指標とする。全取引には重複する銘柄・時期の相関と、元の生存者・選択バイアス、価格範囲補正、日次基準価額と株式約定の時刻差を含む。
