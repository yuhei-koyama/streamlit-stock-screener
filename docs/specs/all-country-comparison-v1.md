## 計算方法と適用条件

公式CSVの「基準価額（分配金再投資）(円)」を使い、購入日と売却日の同日付へ正確に対応付ける。基準価額の終値同士による参考比較とし、申込翌営業日の適用価額や受渡日を再現する実注文シミュレーションは別途条件設定が必要になる。

オルカンの期間損益率を「売却日再投資基準価額÷購入日再投資基準価額−1」とする。元本を1へ正規化すれば、期末額はそれぞれ1＋期間損益率。超過損益率は「戦略の費用控除後損益率−オルカン期間損益率」とし、表ではパーセントポイントで表示する。

戦略の手数料・スリッページは元結果に含まれる値を使う。オルカンはファンド内費用が反映された公式基準価額を使用し、購入・換金の追加費用0、投資家段階の税引前という参照条件を置く。信託報酬や分配金を別加算・控除しない。購入・換金手数料と信託財産留保額の現行情報は三菱UFJ銀行の公式商品情報で確認した。

同日決済は同じ基準価額を対応させ、オルカン損益率を0とする。必要日付が欠落する場合は停止する。日付繰越や前後日からの補完は行わない。期末未決済はこの完了取引の比較集計から分け、元の期末保有件数と評価を参照情報として保存する。

各取引は同額元本なので取引を等加重して比較する。銘柄間・時間帯の重複や取引間の相関を含む。年別表は購入年ごとの取引平均として表示する。資金再利用を規定した年次運用利回りや複利の資産曲線を得るには、資金配分規則が必要になる。今回は同期間の収益差を主結果にする。

## 解釈上の制約

株式の寄付・日中決済と投資信託の日次基準価額には時刻差がある。海外資産の評価時刻と申込不可日も実注文との差につながる。同期間の参考比較という条件を結果へ記載する。元の現在銘柄一覧による生存者・選択バイアスと価格補正の仮定を継承する。超過差の正負は今回の標本の結果として報告する。
