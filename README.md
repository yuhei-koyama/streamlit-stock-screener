# 日本株スクリーナーとバックテスト検証

## Windowsで検索画面を試す

`start_app.bat` をダブルクリックすると、検索画面を起動してブラウザーを開く。初回は仮想環境の作成と必要なライブラリのインストールを自動実行するため、Pythonとインターネット接続を用意する。終了するときは起動ウィンドウでCtrl+Cを押す。

Python 3.11または3.14で、リポジトリのルートから実行する。

```powershell
git switch codex/search-python314
git pull --ff-only origin codex/search-python314
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

ブラウザーで `http://localhost:8501` を開く。左側から銘柄検索、TradingView添付版、各Anti版、初期試作版を選べる。株価取得にはYahoo Financeへの通信を使用する。検索は確定日足を基本にし、対象銘柄と取得期間を画面で指定する。

足種切替と20営業日平均売買代金による共通フィルターは、承認済みの今後の実装項目。現在の運用検討はスイングを中心とし、分足基盤はデイトレ専用ロジックを用意した段階で活用する。

## リンダ系の版別ページ

サイドバーで以下を個別に開けます。既存のAntiトップページと「銘柄検索」も維持しています。

| ページ | 計算・判定 |
| --- | --- |
| TradingView添付版 | EMA3/10/16のクロスとストキャス7/3/10 Hookの同時成立 |
| Anti 310適応版 | SMA3/10/16でのSetup・Hook |

各ページには最新足のBUY/SELL候補フィルター、発生日履歴、チャート、中間値、版ID・パラメータ付きCSVがあります。AntiのBUY/SELL候補はHook Long/Shortで、価格によるentryではありません。試作版は原典準拠ではなく比較用です。詳細は[版別仕様](docs/specs/linda-versions.md)を参照してください。

当日足除外は初期有効で、引け後も当日を除きます。解除すると場中未確定足を含み得ます。自動確定足判定とTradingView実データでの一致確認は未実施です。バックテストでも共通関数`stock_screener.linda_versions.evaluate_version`を使用します。
