# 検索画面の全足種共通・監視対象条件

確定日2026年11月12日。日足・時間足・分足で共通利用する構成と初期値を承認済み。承認記録は`artifacts/intraday-5m-pilot-20261112-01/candidate-filter-approval.json`。初期値の妥当性は対象数・検証成績・実際の発注条件を確認して評価する。

## ユーザー方針

出来高以外にも、トレード対象として適切と判断できる材料を条件案へ含める。条件を追加・変更する際は、内容と数値を提示して承認を得る。

共通の銘柄絞り込みを日足検索にも利用する。共通条件は確定済みの日足から計算し、その候補集合に対して選択した日足・時間足・分足のロジックを判定する。共通条件の20営業日は20本の日足、ATR14は14本の日足として扱う。

## 承認済みの共通絞り込み

検索時点で利用可能な最新の確定日足を基準に候補集合を作る。場中は前営業日まで、引け後は配信完了を確認した当日までを利用できる設計とし、採用した基準日を表示する。バックテストでは、その判断時刻までに利用可能だった確定日足に限定する。閾値は承認済みの初期値。

| 項目 | 採用値 | 目的 |
| --- | --- | --- |
| 対象商品 | 東証の普通株 | 初期対象の範囲を明確にする |
| 流動性 | 基準日までの20営業日の平均売買代金が10億円以上 | 継続的に金額ベースの取引がある銘柄を選ぶ |
| 監視数 | 条件を満たした銘柄を平均売買代金順に最大100銘柄 | 各足種の取得・判定対象を絞る。件数は設定可能にする |
| 値動き | 基準日までの日足ATR14÷基準日終値を参考表示 | 値動きの大きさを利用者が確認する材料にする |
| 購入可能額 | 基準日終値で1単元と買付費用が利用者の上限以内 | 全足種で共通の予算条件として選択可能にする |
| 必要データ | 各指標の準備本数と確認可能な価格系列 | データ不足は理由付きで判定不可として表示する |

売買代金が提供されるデータ源では、その日次値を用いる。OHLCVだけのデータ源では日次終値×出来高を近似値として使い、画面と保存結果に近似であることを示す。実際の約定代金と近似値の採用を記録する。

ATRは日次の真の値幅をWilder方式で14本平滑化して計算する。TRは当日高値−安値、当日高値と前日終値の差の絶対値、当日安値と前日終値の差の絶対値の最大値。価格単位が変わる企業行動と入力欠損を検査する。

基準日・対象一覧の版・条件設定をキーに候補集合を保存する。同じ基準日と条件で日足から5分足へ切り替える場合は、共通の候補集合を再利用する。利用可能な過去時点の上場一覧と採用日・除外日を保存する。

## 承認済みの発注前チェック

休場中も確定日足の共通条件で検索候補を生成する。発注前には最新の株価・気配・市場状態で下表を確認し、取得時刻と判定状態を検索結果に表示する。

| 項目 | 採用条件 |
| --- | --- |
| 売買単位と予算 | 最新価格で1単元の購入代金と買付費用が、利用者の1回の購入上限に収まるか再確認する |
| 市場状態 | 売買停止など注文を執行できない状態は対象から除外する |
| 気配の差 | 最良売気配と最良買気配の差÷両気配の中値が0.2%以下 |
| 気配・市場状態の取得 | 確認可能なデータ源で判定し、未取得の項目は発注前チェックの判定不可として表示する |
| 直近足 | 確定した足の価格・時刻・出来高を確認する |

国内普通株の通常の売買単位は100株。1回の購入上限は利用者の設定値とし、必要資金を画面に表示する。例えば10万円枠では100株の買付費用を含めた判定が必要になる。[JPX売買単位](https://www.jpx.co.jp/equities/trading/domestic/03.html)

日次の平均売買代金は流動性を判断する材料となる。JPXも上場維持基準で流動性の水準として平均売買代金を使用している。今回の20営業日・10億円という初期値は、全足種で共通の監視対象向けに承認された数値である。[JPXの売買代金の説明](https://faq.jpx.co.jp/disclo/tse/web/knowledge7640.html)

## 適用と保存

実装時に採用条件、閾値、参照日、データ源、判定不可の理由、通過・除外銘柄数を保存する。候補の絞り込みと7ロジックの買い判定を対応付けて検証する。各条件を単独で追加した影響も確認できる構成を設計する。

今回の5分足試作は固定20銘柄と仮想端数株を使う仕様で進めており、入力原本と朝9時30分の終端価格近似は承認済み。分足処理の実装・動作検算はユーザーの実装前確認待ち。今回確定した共通条件は将来の検索画面の仕様として記録した。

20営業日・10億円・最大100銘柄・スプレッド0.2%の初期値を使った収益性・対象数は未検証。ATRは参考表示として採用する。対象を絞った結果の再現性は、当時利用可能な情報・対象一覧と独立した期間で評価する。
