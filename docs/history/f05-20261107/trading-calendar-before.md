# 休場日を除外する取引日仕様 v1

2026年11月7日。ユーザーの「休場日はスキップしてほしい」により確定。対象は既存の2016〜2020年・2021〜2025年検証と指標準備期間2014年以降。

## 確定事項

- 土日、内閣府の祝日・振替休日・特例休日、東証の年末年始休業日である1月1〜3日と12月31日を日足処理から除く。
- 取得原本と価格キャッシュは保持し、派生入力・指標本数・RS参照・翌営業日の注文・保有営業日数から一貫して除く。
- 営業日に個別銘柄だけ出来高ゼロだった行は保持する。約定可否は既存の出来高・取引可否判定を使用する。
- 休場日の行は価格品質の補正前に区分する。承認済み197行のうち営業日に残る163行を補正する。残り34行は休場日として除かれる。
- 除外日・理由・元OHLCV・銘柄を保存する。祝日原本・抽出した日付集合・規則版をハッシュで識別する。

## 実装範囲

共有処理は`stock_screener.trading_calendar`。現在の規則は2014年1月1日〜2025年12月31日を対象とし、範囲外はエラーとして原本確認を必要とする。

追加期間の`prepare`は標準で休場日を区分する。追加期間の`run`はカレンダー版のある再準備済み入力を必要とし、RS参照も同じ区分を適用する。`load_dataset`はカレンダー版付き入力の休場日混入・原票ハッシュを検証する。

全市場の`run_batch`も計算前に銘柄と1306.Tを区分し、除外原票とカレンダー版を保存する。以前の規則で完了した結果とはコード版チェックで再開を分ける。

既存の過去結果と補正のみの派生入力は履歴として保持する。新しい派生入力は`artifacts/backtest/period-2016-2020-20261106-01/data-stocks-trading-days-20261107-01/`。

## 実データの確認結果

- 個別株50銘柄で休場日22日分・1,080行を除外。残る営業日の微小補正163行は承認済み一覧の部分集合と完全一致。
- 前回の21日は1306.Tの出来高ゼロの日付。全日付を照合すると2017年7月17日の祝日行も含まれ、22日となった。銘柄ごとの既存行を除くため、22×50件と除外行数は一致しない。
- 営業日の出来高ゼロ92行を保持。営業日入力・約定入力が一致し、他の値は保持された。
- 2021〜2025年用の既存70銘柄入力にも照合し、休場日の混入は0行だった。
- 全111自動テスト成功。休日移動、2019年特例休日、翌営業日の入口と固定保有窓、全市場の指標入力、原本保持、除外履歴ハッシュを検証した。
