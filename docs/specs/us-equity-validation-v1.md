# 米国株の固定条件検証とFX除外 v1（取り下げ）

2026年11月5日。文書版は1.1-proposed。以下の確定事項は会話での明示指示・了承、提案事項と未決定事項は実行前の確認対象として区別する。

## 確定事項

- R-US01。米国株は現行条件を固定して2019〜2025年を一括評価し、購入年別にも結果を確認する進め方を採用する。後半3年を今回の結果閲覧から隔離する案は採用しない。
- R-US02。資金上限を設けず、各買いシグナルを同額元本の独立仮想取引として扱う。現行の7入口設定と保有期限なしの出口A/B/C/Dを比較対象にする。
- R-US03。8%の初期損切り、C/Dの初期利確3R・1R段階更新、既存の費用条件を初期比較値として継続する。米国株の結果を見て条件を変更した場合は、同じ期間への適合を記録する。
- R-US04。FXは検索・売買戦略・バックテストの対象から除外する。円建て評価に必要な為替レートは、米国株の評価用参照系列として扱う。
- R-US05。オルカンとの円建て比較、確定損益と期末含み損益を含む集計、原本・設定・コード・結果の保存を継続する。
- 米国株の対象母集団、相対強度の比較系列、通貨・営業日の対応は調査結果を仕様として提示してから実行する。現時点では米国株の実データバックテストを実行していない。

## 既存コードから確認した現状

- 共通プリセットは日本個別株50・国内ETF20。FXプリセットとFX専用ページは存在しない。手入力から任意のデータコードを受け付ける経路については、FXを専用機能として追加する仕様はない。
- バックテスト入力検証とデータ準備は固定の日本70銘柄を参照する。米国銘柄への差し替えにはデータ契約の対応が必要。
- ミネルヴィニ派生版のRS126は比較対象系列を受け取れるが、バックテスト側は1306.Tを固定参照する。
- 日付正規化にはAsia/Tokyoの指定がある。米国セッション日と約定時刻を分離し、日本の投資信託の日付へ対応させる条件が必要。
- 取得処理は2019年開始。2019年初めから指標を判定するには、それ以前の準備期間を追加する必要がある。
- 既存の63行の価格補正は、承認した日本株データの特定行に限定される。米国株で新たな不整合が判明した場合は内容を記録して対応を確認する。

## 対象母集団の調査

S&P500を候補とする。過去時点の構成銘柄・除外銘柄・名称変更と、対応する価格履歴を扱えるか確認する。現在の構成銘柄だけを過去へ適用した場合には、生存者・選択バイアス付きの探索結果という条件を表示する。

公式ページではS&P500が米国大型株の指数であることを確認した。WRDSの過去構成銘柄照会はCRSP契約を必要とする。Sharadarは1998年以降の追加・除外・発効日・四半期スナップショットを案内しており、有効なAPIキーが必要。無料で過去母集団と上場廃止を含む価格を一式取得できることは未確認。

無料を優先する。契約・有料サービスを利用する場合は費用と利用条件を確認してから判断する。無償公開の履歴資料は出所と整合性を確認し、確認済みデータと区別して扱う。

## 提案事項

- R-USP01。米国個別株の母集団をS&P500の過去構成から定義する。構成外となった後の保有の扱いと上場廃止時の価格・対価も定める。
- R-USP02。取得準備期間を2017年以降とする案。2019年初めまでにSMA200、20本前のSMA200、252本高安値等の準備に十分な有効行があるかを確認する。新規上場銘柄は準備できた日から判定する。
- R-USP03。米国株のミネルヴィニ派生版の比較系列を、S&P500連動ETFのSPY調整済み価格とする案。RS126の計算式を共通関数で継続する。SPYは参考系列として分離し、対象個別株の売買母集団とは別にする。
- R-USP04。米ドル建てのシグナル・価格出口を計算し、円建て収益率を「(1＋米ドル純損益率)×売却時USD/JPY÷購入時USD/JPY−1」で評価する案。為替換算費用の仮定と、参照レートの時刻を明記する。
- R-USP05。米国セッションと夏時間・短縮取引日、オルカンの日本営業日を明示する。欠損NAVや時刻差の処理規則を先に定め、比較から漏れた取引があれば件数・理由を保存する。

## 実行前の未決定事項

1. 過去母集団と除外・上場廃止銘柄の価格を利用可能なデータ源で確保できるか。探索用に現在の構成へ限定する場合の採否。
2. SPYを米国株用のRS比較対象とするか。
3. 円換算に使う為替レートの時刻・費用と、米国セッションからオルカンの基準価額への日付対応。
4. 日本の投資信託に基準価額がない米国営業日の扱いと、検証期末の共通評価日。
5. 検証対象としての米国株と、アプリの検索プリセットへの米国株追加をどの範囲で同時に進めるか。FXは対象外として確定済み。

これらを条件へ追加する前に仕様確認を行う。現段階の高水準の確認方針は、入口関数の共有、準備期間、当時の母集団、時差・為替、各出口の約定、同額元本、基準価額との対応と結果保存の確認とする。

### 代理母集団の固定規則

State StreetのSPY商品ページには公式の全保有明細の日次ダウンロード導線がある。取得時に明細の基準日、原本とハッシュを保存する。株式行を採用し、現金・通貨・先物等の行は対象外とする。異なる株式クラスは別の銘柄として保持する。明細から識別できない資産は自動で株式へ推定せず停止して確認する。SPY自体は戦略の売買対象に加えない。

価格の未取得・履歴不足は銘柄名・理由を保存する。過去価格が取得できない銘柄を別銘柄へ入れ替えない。新規上場銘柄は利用可能な履歴で指標が準備できた日から判定する。新たなOHLC不整合は今回の日本株用補正へ自動追加せず記録して確認する。

### 日付と評価の固定規則

- シグナル・注文の営業日は米国セッション日を基準にし、2019年1月2日〜2025年12月31日を評価対象候補とする。取得準備期間は2017年1月1日以降。
- 価格・出口は米ドルの同じ調整系列で計算し、円建て評価で通貨変動を反映する。米ドルの損益率も補助列に保存する。
- USD/JPYは米国セッション日と同じ日付の保存済み日次終値を使う。必要な為替日が欠けた場合は停止する。
- オルカンは当該日付以前の最後の公表価額を参照する。履歴開始前、または直前公表日から14暦日を超える場合は停止する。参照日・日数差・同日一致件数を保存する。
- 期末未決済も同じ規則で円建て時価とオルカンを評価する。未発生の売却費用は従来どおり含めず記録する。
- この日次参考比較の仮定を結果表・報告書に表示する。投資信託の購入申込・翌営業日の適用価格・受渡日を再現するための実注文条件は別の仕様となる。
- アプリの検索プリセット追加とは切り分け、今回の米国株バックテストを先行対象とする。

上記3項目は新たな比較条件であり、承認前に依存する実装と実データバックテストを開始しない。承認後に詳細テスト設計・実装計画を作成する。
