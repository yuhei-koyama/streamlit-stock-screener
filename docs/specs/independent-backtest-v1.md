# 独立仮想取引の補助診断

更新日2026年11月7日。R-IV01〜R-IV06の初回承認は2026年11月5日。現在の主検証は[有限資金仕様](finite-capital-primary-v1.md)に定め、本書は入口・出口の補助診断へ適用する。

## 継続する承認条件

- R-IV01。各買いシグナルを独立評価し、同一銘柄で重なる取引も対象とする。
- R-IV02。購入費用込みの元本を1へ正規化し、端数数量で純損益率を比較する。
- R-IV03。資金上限・同時保有数による見送りを設けない。
- R-IV04。翌営業日寄付、共有出口、片道手数料0.1%、成行スリッページ0.05%を使用する。
- R-IV05。検索の7設定と共通判定関数を使用する。対象・期間は実行条件と[対象仕様](full-market-validation-v1.md)に記録する。
- R-IV06。再利用可能な結果・条件・ハッシュを保存し、説明文書は日本語とする。

初回は70銘柄・2021〜2025年・出口A/B・初期8%・保有期限付きの14条件で実施した。後続承認による期限撤廃・C/D・損切り5水準・固定保有5期間は[入口・出口診断](entry-exit-diagnosis-v1.md)へ定義する。初回の詳細は[履歴](../history/f05-20261107/independent-backtest-before.md)に保存した。

## 現在の処理

実装は`stock_screener.independent_backtest.run_independent_backtest`。各確定足のreadyとbuy_signalから次の取引営業日寄付の取引を作る。営業日の取引不可は既存規則で記録し、休場日と全日停止は[カレンダーv2](trading-calendar-v1.md)で入力から除く。

調整OHLCを使用し、分割・配当は価格調整へ含める。期末保有の時価評価と完了取引の統計を区分して保存する。全取引、未決済、見送り、注文履歴、銘柄・購入年・資産区分別の集計、入力・コード・規則版を保存する。

## 評価の単位

取引ごとの平均・中央値・勝率・利益損失・保有期間と同期間オルカン差を報告する。期間が重なる取引を含むため、有限資金の純資産曲線・CAGRは主仕様の会計で別途評価する。

[既存の診断結果](../../artifacts/backtest/entry-exit-diagnosis-20261105-01/REPORT.md)は保存当時の条件で参照できる。新規計算では実行前の休場日検証と現在の入力要件を適用する。
