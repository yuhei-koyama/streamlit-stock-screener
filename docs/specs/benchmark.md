# オルカンおよび補助ベンチマーク比較仕様

作成日: 2026-11-05 / 版: 1.0-draft / 状態: **提案・未承認**

## 1. 第一ベンチマーク

eMAXIS Slim 全世界株式（オール・カントリー）の実ファンド基準価額を第一選択とする。公式運用報告書では、設定日は2018-10-31、対象指数はMSCI ACWI（配当込み、円換算ベース）である。

実ファンド基準価額を使う理由:
- 円建てであり、別途USD/JPY換算を作らない。
- 実際の運用差、現金、ファンド内費用の影響を含む。
- 基準価額には信託報酬が反映されるため、同じ費用を別途差し引かない。

資料:
- [三菱UFJアセットマネジメント公式運用報告書](https://www.am.mufg.jp/pdf/zenunyou/253425/253425_20250425.pdf)
- [公式FAQ: 分配方針](https://faq1.am.mufg.jp/answer/6745317d04b4dd5d0ebdc64c/)
- [三菱UFJ銀行の商品ページと基準価額CSV導線](https://fs.bk.mufg.jp/webasp/mufg/fund/detail/chart/m00355920.html/csv/m00355920.csv)

公開CSV導線は確認できたが、自動取得API、履歴保持期間、自動アクセス条件は確定していない。初期候補は、利用者が公式サイトから取得したCSVをローカルに取り込み、出所・取得日・ハッシュを保存する方法とする。自動取得は利用条件確認後に判断する。

## 2. 同一条件の比較

### 一括投資シナリオ
- 共通の開始日、終了日、初期資金。
- 戦略は開始日の資金制約に従い、オルカンは承認した申込・約定日規則で口数化。
- 外部入出金なし。累積リターン、CAGR、最大DD、Sharpe、Sortino、最終資産を比較。

### 積立シナリオ
- 共通の初期資金、積立額、頻度、入金日。
- 休業日の繰越規則、オルカンの申込から基準価額適用までの規則を固定。
- 戦略側は同日に現金を受け取り、その後の注文規則に従う。未使用現金も資産に含む。
- 最終資産、累計入金、TWR、XIRR、最大DDを比較。単純な最終/初期をCAGRと表示しない。

両シナリオを実行する案を推奨するが、金額・日・口座区分は未決定。

## 3. 分配金・費用・税

- 実ファンド基準価額は信託報酬控除後なので、信託報酬を再度控除しない。
- 分配がある場合、基準価額だけではなく税引前分配金を同じ条件で再投資したTotal Return系列を作る。無分配を将来まで仮定しない。
- 購入時手数料、信託財産留保額、販売会社固有条件は比較時点の公式資料と利用条件を確認する。
- 税はNISA/課税口座等に依存する。まず税引前比較を標準にする案があるが、承認が必要。税引後を行う場合は戦略とオルカンに同じ口座仮定を適用する。
- 戦略側は手数料・スリッページを明示し、コスト0、現実的、ストレスの感応度を併記する。

## 4. 比較可能期間

主結果は、実ファンド設定日以降かつ戦略・ベンチマーク双方の品質を満たす共通期間に限定する。ウォームアップ期間は成績期間に含めない。

設定日前の期間を含める場合は、次の代理系列を別結果として扱う。

1. MSCI ACWI配当込み・円換算: 概念的には最も近いが、日次履歴の無償取得・再利用ライセンスを確認できていない。
2. 東証上場の全世界株ETF: 市場価格乖離、売買コスト、分配金、信託報酬、設定日の差がある。
3. 米国ETF＋USD/JPY: 指数、税、取引時間、経費、配当、為替換算が異なる。

代理系列と実ファンドを接続して、全期間を「オルカン実績」と表示しない。

## 5. TOPIX補助ベンチマーク

日本株市場との比較には配当込みTOPIXを優先する。価格指数だけを使うと配当分が欠け、配当を含む戦略との比較が歪む。

J-Quants FreeではTOPIX系列を得られず、プラン別に利用範囲が異なる。JPXウェブページでは現在値と短い履歴を閲覧できるが、長期の日次バックテスト用データの取得・保存条件は別途確認が必要である。

資料:
- [JPX: TOPIX](https://www.jpx.co.jp/markets/indices/topix/)
- [JPX: 配当込み指数](https://www.jpx.co.jp/markets/indices/related/ratio/)
- [JPX: 指数現在値](https://www.jpx.co.jp/markets/indices/realvalues/)
- [J-Quantsプラン別データ](https://jpx-jquants.com/ja/spec/data-spec)

## 6. 比較レポート

最低限、次を同じ画面・表で示す。

- データ期間、入出金、費用、税、再投資、データ品質ラベル
- 戦略、オルカン、配当込みTOPIXの資産推移
- CAGRまたはTWR/XIRR、最大DD、Volatility、Sharpe、Sortino
- 年次リターンとローリング期間リターン
- オルカンとの差（年率、最終資産、DD、リスク調整後）
- 戦略の現金比率、取引数、コスト、データ除外数
- IS/OOSとウォークフォワードの別

過去に上回った事実から将来の超過を結論付けず、比較期間、相場局面、試行数、OOSの長さを併記する。
