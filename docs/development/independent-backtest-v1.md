# 独立仮想取引のテスト設計と実装計画

2026年11月5日。承認対象はindependent-backtest-v1.mdの1.0-approved、R-IV01〜R-IV06。

## テスト設計

| 要求 | 固定合成データによる期待値 |
| --- | --- |
| R-IV01・03 | 2銘柄に連続3日の買いを与え、翌寄付から6件の独立建玉を得る。資金と最大保有設定を変えても取引と損益率が一致する。 |
| R-IV02・04 | 価格100の買いと110の反対候補決済で、正規化元本1と手数料・スリッページから求めた損益率に一致する。 |
| R-IV04 | 既存エンジンと同じ単独シグナルについて、期限・ギャップ・RSI回復・ミネルヴィニの翌日有効トレーリングの売却日、価格、損益率が一致する。 |
| R-IV04・05 | 未来の価格を変更しても過去の決済履歴が一致し、当日終値の買いが翌寄付で約定する。 |
| R-IV03・06 | 期末シグナル、売買不可、未決済、空の取引一覧も読み取り可能な列付きCSVへ保存する。 |
| R-IV05・06 | 70銘柄の固定合成入力から通常CLIで14条件を実行し、状態・集計・保存ファイルを確認する。 |
| データ品質 | 価格範囲不整合は検出時に停止し、実データの停止理由を記録する。 |

## 実装計画

1. 既存バックテストから入力検証と引け時の出口判断を共通処理へ抽出する。
2. 共通処理を使う独立取引評価を追加する。正規化元本1に対する仮想数量で計算する。
3. 既存CLIに明示的な評価方法の選択を追加し、独立評価の保存処理を接続する。
4. 回帰テストと通常CLIの合成データ実行を行う。
5. 実データ入力を検証し、補正が必要な場合はその承認を確認する。結果と制約を日本語で保存する。
