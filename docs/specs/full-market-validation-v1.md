# 東証全銘柄の追加期間検証

2026年11月6日、ユーザーは「東証上場の個別株・国内ETF全体」を選択した。現在の公式一覧を固定した探索検証として、2016〜2020年と2021〜2025年を同じ条件で比較する。上場廃止銘柄が含まれない生存者バイアスを明記し、当時の全銘柄を網羅したとは呼ばない。

対象はJPX最新一覧のプライム・スタンダード・グロースの内国株式と、国内上場ETFの公式一覧で照合できるETF。外国個別株、ETN、REIT、インフラファンド、TOKYO PRO Marketは今回の一般投資家向け検証対象外。ETF・ETN混在区分をETFとして丸ごと扱わない。公式一覧の原本・日付・ハッシュ・採否理由と銘柄数を保存し、両期間で同じ母集団を使用する。

検索の共有7入口と既存HORIZONS/STOPS/出口A〜Dを固定。入口式を再実装しない。銘柄ごとに分割処理し、保存データと結果を検証して再開する。調整済み日足・同額元本の独立仮想取引・翌寄付・既存費用を維持。資金上限・同時保有上限なしの取引平均であり、実ポートフォリオ年率とは区別する。

ローカル用ワークフローを整備し、クラウドでは全市場の大量価格取得を行わない。データ不整合・負価格を自動補正しない。取れない銘柄や未処理銘柄を除いて全市場検証完了とは表示しない。上場前等で期間内に履歴がない場合も件数を分けて記録する。価格補正の未解決事項R-DQ05は引き続き有効。

JPXの一覧を取得できず、本実装では実際の全銘柄数や検証成績を未確認。件数を推測しない。検索画面からの削除・main反映・最適化・新しい戦略条件は今回行わない。
