状態: 売買条件の確認待ち。2026-11-05の追加依頼によりシステム実装は許可されたが、下記は原典ではなく初期の比較用ルール案である。

## 実施範囲
既存Antiスクリーナーを維持し、共通ロングオンリーエンジン、3戦略、評価指標、比較ページを追加する。検証は少量の固定合成データのみ。実市場の取得・評価、最適化、ウォークフォワード実行、デプロイ、実注文を行わない。

## 売買条件案（承認対象）
- Anti: 既存3/10版のhook_longをそのまま買い候補に使用。hook_shortを通常出口に使用。ストキャス版は既存表示を維持し今回の比較対象から外す。初期ストップは取得価格の8%下。最大20営業日保有。
- ミネルヴィニ派生版: Close > SMA50 > SMA150 > SMA200、SMA200 > 20本前のSMA200、Close >= 252本安値の1.3倍、Close >= 252本高値の0.75倍。RSは明示されたベンチマークに対する126本リターン比が1超（専有Ratingではない）。Closeが当日を除く20本高値を超え、Volume > 過去20本平均の1.5倍で買い候補。取得価格8%下のストップと、前日までの保有後最高値10%下のトレーリング。RS用データ欠損は不成立。
- RSI平均回帰: Wilder平滑RSI、期間2/14を個別設定。初期の閾値は期間2が10、期間14が30。RSIが閾値未満なら買い候補、RSI >= 50または5営業日保有で通常出口。Close > SMA200フィルターを初期有効とし切替可能。取得価格8%下のストップ。

## 共通約定・会計案（承認対象）
終値確定シグナルを次の利用可能な取引日の始値で処理する。売却を買付より先に処理し、同時候補はティッカー昇順。初期資金100万円、最大5銘柄、各枠は買付時総資産の20%以内、現金を超えない単元数へ切り捨て。単元は入力必須でETFを100株と推測しない。手数料片道0.1%、スリッページ片道0.05%を初期値として設定可能にする。
ストップを飛び越えた寄付は寄付、通常はストップ水準で不利なスリッページを加算する。同日の損切りと利確が競合した場合は損切り優先。トレーリング更新は引け後に翌日から有効。出来高0・バー欠損は約定不可、最終日は強制決済せず評価額と未決済建玉を報告する。

## データ・評価
初版は利用者のローカルCSVを入力とし、アプリ起動時に外部取得しない。価格系列・単元・銘柄区分・ベンチマーク名を明示。分割・配当の会計を提供しない入力は探索用と表示し、調整済み価格へ配当を二重加算しない。オルカンは本人が明示した系列のみ使用し、代替は代替と表示する。
CAGRは未投資現金込みの総資産と実日数で計算。MDD、Sharpe（無リスク0、252日）、Calmar、月次・年次リターン、取引統計、コスト、現金比率を表示。実データランキングは今回生成しない。
