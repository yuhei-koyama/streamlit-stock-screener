# 検索画面の利用手順

## 起動

Windowsではリポジトリ直下のstart_app.batをダブルクリックする。Pythonと必要なライブラリを確認して検索画面を開く。初回のライブラリ導入と株価更新にはインターネット接続が必要となる。

ブラウザーの表示先は http://localhost:8501 。終了するときは起動ウィンドウでCtrl+Cを押す。

## 銘柄検索

1. 東証普通株、国内上場ETF、コード指定から対象を選ぶ。コード指定はカンマ・空白区切りで入力する。
2. 入口を7種類から選択する。複数選択では、ORはいずれか成立、ANDはすべて成立の条件となる。
3. 判定基準日を指定する。通常は前営業日までを使用し、当日値は実行ごとに手動で選択する。当日値には暫定表示を付ける。
4. 流動性条件を設定する。初期は20営業日平均売買代金10億円以上・上位100銘柄。OFFにすると下限と上位件数の制限を解除し、選択対象全体に入口判定を適用する。
5. 必要に応じて購入予算をONにする。流動性条件のON／OFFとは独立して使用できる。
6. 初回の全市場検索では全体データ準備を実行する。保存済みの価格を再利用し、進捗と取得失敗を表示する。途中で止まった場合も、次回の準備で取得済み銘柄を再利用する。
7. この条件で検索を押す。検索中は流動性・予算と入口条件の判定進捗を表示する。

成立、不成立、判定不可、対象外を切り替えて一覧を確認できる。PCは表、画面幅760px以下はカード表示を基本とする。銘柄を選択すると詳細へ進める。

上場一覧は基準日を表示する固定スナップショット。コード指定では一覧未確認のコードも検索できる。売買単位を確認できない場合は購入額を確認待ちとする。過去日検索は現在配信されている価格系列と表示した上場一覧を使うため、当時の上場銘柄全体の再現には制約がある。

平均売買代金は終値×出来高の概算。ATR14は参考表示。流動性OFF時も、必要な価格・RS参照・指標準備本数の不足は判定不可として表示する。

## 条件の保存

上部の保存名に名前を入力し、現在の条件を保存する。設定は利用端末のブラウザー内に保存する。保存した設定を選び、呼び出すと復元できる。当日値の使用は各実行時に手動選択する。

詳細から戻る際は検索条件と結果ページを保持する。条件変更後の画面には、保存結果で使用した条件を併記する。価格データや判定処理の版が変わった場合は、その状態を表示して再検索へ案内する。

## 銘柄詳細

ローソク足と入口ごとの指標・合否・数値を確認する。価格取得日時と売買単位の資料基準日も表示する。

これから購入する想定では、想定約定価格から初期ストップ・利確水準・想定損失を計算する。過去日の寄付に購入した想定では、購入日以後の価格と共有の出口処理で参考経路を表示する。決済条件に達した場合は参考決済日・理由・損益を表示する。

出口Aは初期損切り固定、Bは入口ごとの売却条件、Cは損切りの切り上げと固定利確、Dは損切りと利確の双方を切り上げる。C/Dは購入価格の8%を基準幅とし、初期利確は24%。更新後の水準は翌営業日から有効となる。

概算費用の初期値は片道手数料0%・成行スリッページ0.05%。SBI証券の手数料無料適用を前提とする試算で、費用は変更可能。金額は税引前。ギャップや急変では想定損失額を超える場合がある。

気配、スプレッド、売買停止状態は発注前の確認事項として表示する。確認できた情報と確認待ちを画面で区分する。

## 検証結果

2016〜2020年・2021〜2025年、個別株・ETF、入口・出口・初期損切りに対応する保存済み成績を参照する。期末資産・年率・最大下落率・決済件数・1取引平均純損益と資産推移を表示する。

期末資産は含み損益を含み、1取引平均純損益は決済済み取引の標本平均。2016〜2020年のオルカン欄は実ファンド設定前を含む扱いとなる。

検証条件の固定対象、仮想端数株・費用込み10万円枠、費用設定を併記する。流動性・予算・実売買単位、入口パラメーター変更、複数入口のOR／ANDを追加した設定には、参照成績との差と未検証の表示を付ける。

## データと更新

価格と検索結果の保存先はoutputs/screener/。取得した価格のファイルハッシュと取得日時を対応付け、同じ銘柄を同時に更新する処理をファイルロックで制御する。分割や配当調整による価格単位の変化を検出した場合は、履歴を再取得する。

同梱営業日規則は2014〜2026年を対象とする。営業日規則の更新から内閣府の公式祝日を取得し、対応年を更新できる。

検索用上場一覧・ETF売買単位・検証結果の軽量版はdata/screener/に同梱する。検証結果は完成した保存版に切り替えて公開し、切替前後のデータが混在することを防ぐ。

確認済みの一般市場開始日と8303.T・9204.Tの再上場日より前の履歴は、検索指標の計算から除く。同梱一覧の開始日が未確認の銘柄については、配信履歴の制約が残る。
