# 取引日カレンダーの現行仕様

更新日2026年11月7日。現在版は`jpx_cash_sessions_2014_2025_v2`。対象範囲は2014年1月1日〜2025年12月31日。

## 確定した規則

- 土日、内閣府の祝日・振替休日・特例休日、東証の1月1〜3日と12月31日の休業を除外する。
- 2020年10月1日の東証全銘柄の終日売買停止を例外日へ含める。理由は`exchange_full_day_halt`。
- 指標本数、RS参照、翌営業日の注文、OCO更新の有効日、保有営業日数へ一貫して適用する。
- 営業日に個別銘柄だけ出来高ゼロだった行は保持し、約定可否は既存判定で扱う。
- 原本を保持し、除外日・銘柄・元OHLCV・理由・規則版・根拠とハッシュを保存する。

[内閣府の祝日原本](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)、[JPX休業日](https://www.jpx.co.jp/corporate/about-jpx/calendar/)、[2020年10月1日の公式告知](https://www.jpx.co.jp/news/1030/20201001-04.html)を根拠とする。

## 実行と参照

共有処理は`stock_screener.trading_calendar`。通常CLI・入口出口診断・追加期間・全市場バッチで計算前に検証する。追加期間と全市場の準備では、価格品質検証・指標計算より先に休場日の区分を行う。

| 入力 | 参照 | 新規計算 |
| --- | --- | --- |
| v2 | v2として検証 | 現在のv2で検証 |
| 既知のv1 | 当時のv1として検証 | v2への再準備を案内 |
| 版の記録がない旧形式 | 保存状態を参照 | 現在の規則で実行前検証 |
| 未知の版・メタデータ不一致 | 確認を要する状態として停止 | 停止 |

全市場バッチはコード・規則・入力をフェーズ別に照合し、混在を拒否する。範囲外の日付はカレンダー原本の追加確認を必要とする。

## 確認結果

個別株50銘柄の休場日22日分1,080行を区分し、承認197行のうち営業日163行を補正、休場日34行を記録した。営業日の出来高ゼロ92行を保持した。

2020年10月1日は既存原本に行がなかったため、v2移行に伴う価格行の追加除外は0行。準備期間を含む保存範囲では2016〜2020年用1,708日、2021〜2025年用1,706日で、新版の期待取引日との差は0日だった。任意の全市場共通の取得欠損の自動分類は残る検討事項。
